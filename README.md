# AO3 Skins Hub

A growing collection of **AO3 skins** for Archive of Our Own.

Here you'll find both **AO3 Site Skins** and **AO3 Work Skins** — from nostalgic desktop-inspired themes to custom layouts for individual works.

New skins will be added over time.

More **AO3 work skins** will be added to this repository over time.

## How to Use an AO3 Site Skin

1. Sign in to [Archive of Our Own](https://archiveofourown.org/).
2. Go to **Dashboard → Skins → My Site Skins**.
3. Click **Create Site Skin**.
4. Give your skin a title.
5. Open the CSS file you want to use from this repository.
6. Copy the CSS and paste it into the **CSS** field on AO3.
7. Click **Submit**.
8. Open your new skin and click **Use**.

That's it — AO3 should now use your new Site Skin.

You can switch skins or return to the default AO3 appearance at any time.

## How to Use an AO3 Work Skin

Work Skins are a little different from Site Skins.

They are generally created from **Dashboard → Skins → My Work Skins** and then selected when publishing or editing a work.

Each Work Skin in this repository may have slightly different setup instructions, so check the README or notes included with that skin.
